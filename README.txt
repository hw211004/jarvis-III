J.A.R.V.I.S. MARK III ALPHA — iPhone-only deployment

1. On your iPhone, sign up at https://github.com (free account).
2. Create a NEW PUBLIC repository named jarvis-mark-iii. Do not upload personal data or backups to the repository. The app code will be public.
3. Upload the five files from this folder to the repository ROOT: index.html, manifest.webmanifest, sw.js, icon.png, icon-512.png. In GitHub's mobile browser, you may need to request Desktop Website to find Add file > Upload files.
4. In the repository, open Settings > Pages. Under Build and deployment, select Deploy from a branch; branch main; folder /(root); Save.
5. Wait for GitHub Pages to publish. Visit https://YOUR-USERNAME.github.io/jarvis-mark-iii/ (replace YOUR-USERNAME).
6. In Safari tap Share > Add to Home Screen, enable Open as Web App if offered, then Add.
7. Open JARVIS from your Home Screen. Run 'system report', save a priority, log readiness, and export a backup.

COST: $0 for GitHub Free public repository and Pages static hosting, within usage limits.
LIMITATIONS: This alpha has no connected AI model, wake word, background listening, microphone recognition, live calendar or notifications. Speech synthesis may or may not play depending on browser support. Records are stored in browser localStorage on this device, not encrypted or synced; deleting website data can erase them. Export backups regularly. Avoid storing sensitive health, financial, military or personal identifiers. A public repo exposes the code but not local records unless you upload them yourself.

IMPORTANT: Offline use requires a successful first online load and service worker installation. iOS may evict cached assets; don't rely on guaranteed offline availability. The application is not yet deployed until you complete the steps above.
